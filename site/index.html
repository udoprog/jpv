jpv

A fast Japanese dictionary that runs on your own machine. jpv builds a local database from JMdict and Kanjidic and serves it through a browser interface, so lookups work offline and stay private.

  • Search in Japanese or English, with wildcards.
  • Paste a conjugated word and jpv works out its dictionary form and how it was inflected.
  • Kanji details: readings, meanings and stroke counts.
  • Clipboard capture, including OCR of screenshots through tesseract, and a GNOME extension to feed it.
  • Fully offline once the dictionary is built, and quick to start: the database is memory mapped.
  • Light and dark themes, and an interface in English or Japanese.

Install

curl -fsSL https://udoprog.github.io/jpv/install.sh | sh

Installs the latest prebuilt jpv into ~/.local/bin on Linux (x86_64) and macOS (Apple silicon). Set JPV_INSTALL_DIR to install elsewhere, or JPV_VERSION to a release tag to pin one. These portable builds use OCR when tesseract and its Japanese language data are installed.

Fedora: the RPM from the releases includes OCR, the desktop entry and GNOME integration. Windows: use the MSI from the releases.

Get started

jpv build                  # download and build the dictionary (once)
jpv service --background   # run the dictionary service in the background
